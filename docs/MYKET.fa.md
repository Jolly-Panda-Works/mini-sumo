# نسخه‌ی مایکت

نسخه‌ی مایکت همان بازی است و کنار نسخه‌ی بازار روی شاخه‌ی `Iranian-store` ساخته می‌شود (**Actions ← Iranian stores**). نسخه و versionCode با بازار یکی است و Release آن تگ `myket-vX.Y.Z` می‌گیرد. برای به‌روز کردن شاخه و یادداشت نسخه، [BAZAAR.fa.md](BAZAAR.fa.md) را ببینید؛ هر دو فروشگاه از یک یادداشت استفاده می‌کنند.

تفاوت با نسخه‌ی بازار:

- **پرداخت درون‌برنامه‌ای مایکت:** کتابخانه‌ی `ir.myket:billing`، با همان شناسه‌ی محصول‌های بازار. سرور هر خرید را با API مایکت بررسی می‌کند.
- ورود با بازار و صفحه‌های بازار را ندارد. ذخیره با ایمیل در دسترس است.
- دکمه‌ی به‌روزرسانی صفحه‌ی بازی در مایکت را باز می‌کند.

## رهانش خودکار در مایکت

بعد از هر بیلد موفق شاخه، APK امضاشده با API مایکت فرستاده و درخواست بررسی ثبت می‌شود (`tools/myket-release.mjs`).

راه‌اندازی (یک بار):

1. برنامه را با همان package name یعنی `com.jollypanda.mini_sumo` در پنل توسعه‌دهندگان مایکت ثبت کنید.
2. از صفحه‌ی برنامه، توکن صحت‌سنجی را بگیرید.
3. GitHub ← Settings ← Secrets and variables ← Actions ← Secrets: `MYKET_ACCESS_TOKEN` = همان توکن.
4. (اختیاری) Variables: `MYKET_AUTO_PUBLISH`: `false` (پیش‌فرض) یعنی خودتان در پنل منتشر کنید؛ `true` یعنی بعد از تأیید خودکار منتشر شود.

## پرداخت درون‌برنامه‌ای

1. در پنل مایکت، بسته‌های سکه را با همان شناسه‌های جدول [BAZAAR.fa.md](BAZAAR.fa.md) بسازید (مثل `coin-lucky`).
2. کلید عمومی پرداخت را از صفحه‌ی برنامه بردارید و در `apps/mobile/myket.config.json` (کلید `publicKey`) یا متغیر مخزن `MYKET_PUBLIC_KEY` بگذارید.
3. روی سرور، در `.env` بگذارید: `MYKET_ACCESS_TOKEN=...`، بعد `git pull` و `docker compose up -d --build`. در لاگ سرور باید `[myket] Myket accepts the token from this server` را ببینید.

تا وقتی کلید عمومی در بیلد و توکن روی سرور نباشد، خرید با پول در حالت آنلاین فعال نمی‌شود و هیچ پولی گرفته نمی‌شود.

## نکته‌ی ارسال

تا وقتی secret `MYKET_ACCESS_TOKEN` در GitHub نباشد، نسخه‌ی مایکت فقط ساخته می‌شود و چیزی به مایکت نمی‌رود. اگر مایکت همین versionCode را داشته باشد (در حال بررسی یا تأییدشده)، ارسال انجام نمی‌شود.
