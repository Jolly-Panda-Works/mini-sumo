# تبلیغات نسخه‌های بازار و مایکت

دکمهٔ تماشای تبلیغ در فروشگاه سکه برای هر نمایش کامل ۵۰ سکه می‌دهد. سقف روزانه ۵ پاداش است. نسخهٔ آنلاین پاداش را با شناسهٔ نمایش تپسل و پس از تأیید سرور ثبت می‌کند.

پس از ۴ یا ۵ مسابقه، تبلیغ تمام‌صفحه هنگام خروج از صفحهٔ نتیجه قابل نمایش است. محصول `remove_ads` تبلیغ بین مسابقه‌ها را غیرفعال می‌کند. مالکیت محصول از فهرست خریدهای استور بازیابی می‌شود و خود محصول مصرف نمی‌شود.

## تنظیم بیلد

- راز GitHub Actions با نام `TAPSELL_APP_KEY`
- متغیرهای GitHub Actions با نام‌های `TAPSELL_REWARDED_ZONE` و `TAPSELL_INTERSTITIAL_ZONE`
- محصول یک‌بارخرید `remove_ads` در بازار و مایکت. قیمت از استور خوانده می‌شود.

این سه مقدار تپسل برای بیلد محلی هم به‌عنوان متغیر محیطی استفاده می‌شوند. پلاگین اندروید فقط در بیلدهای Bazaar و Myket اضافه می‌شود.

## فعال‌سازی پاداش آنلاین

برای تبلیغ‌گاه جایزه‌ای، [صحت‌سنجی S2S](https://developer.tapsell.ir/docs/sdk-legacy/platforms/s2s/) را از پشتیبانی ناشران تپسل درخواست کنید. پس از تأیید پشتیبانی، نسخهٔ جدید سرور را مستقر کنید و `AD_REWARDS_ENABLED=true` را در تنظیمات سرور بگذارید. فعال‌سازی را با یک نمایش کامل، یک نمایش نیمه‌کاره و ثبت مجدد همان شناسه بررسی کنید.
