# بیلد مرکزی Mini Sumo

شناسهٔ فعلی بدون تغییر: com.jollypanda.mini_sumo.

سورس بیلد برنچ Iranian-store است. بیلدر عمومی game-builds با GitHub App سورس را می‌خواند، تگ stores-vX.Y.Z روی commit واقعی می‌زند و فایل‌ها را در Releases همین ریپو می‌گذارد. Topic tgbot برای ارسال توسط Panda Radar است؛ توکن خود بات نیز باید ریپو را ببیند.

همان چهار Secret امضای فعلی از سورس، به‌صورت رمزگذاری‌شده، به Environment mini-sumo منتقل می‌شوند. APK/AAB بازار و مایکت با همان شناسه و امضا ساخته می‌شوند.

APK مستقل Debug شناسهٔ com.jollypanda.mini_sumo.debug دارد و کنار نسخهٔ اصلی نصب می‌شود. برای تست قبل از انتشار است؛ هیچ API انتشار استوری فراخوانی نمی‌شود. Grid Rush همان debug.keystore ثبت‌شدهٔ قبلی را حفظ می‌کند. کلید دیباگ runner در پروژه‌های دیگر ممکن است بین اجراها فرق کند.

بیلدهای قبلی در Actions غیرفعال می‌شوند تا هم‌زمان دو مسیر نسخه/تگ تولید نکنند. کد اصلی بازی و شناسه‌ها عوض نشده‌اند. پروژه‌های بومی ثبت‌شده حفظ و فقط پروژه‌های Android تولیدشونده در CI دوباره ساخته می‌شوند.

تست محلی: npm ci و npm test. برای ساخت Android مقدار STORE=debug و VERSION=X.Y.Z را تعیین و npm run build:android اجرا کنید. خروجی وب در این مسیر فعال نیست.
